# Tailwind Ripple Animation

A sleek ripple hover effect button built using **React**, **Vite**, and **Tailwind CSS**.  
Mouse track karta hai aur ripple animation usi point se expand hoti hai — ek elegant UI interaction.

---

## 📦 Features

- Fast and lightweight – Vite-powered React app  
- Tailwind CSS ke saath utility-first styling  
- Real-time ripple animation based on mouse position  
- Reusable **RippleButton** component
